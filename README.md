# MeiheweitePro（梅赫维特 Pro）

基于 **YGOProUnity_V2** 二次开发的《游戏王》模拟器客户端，使用 Unity 构建。

本仓库是与发布版二进制**对应的完整源码**，用于履行 GPL-3.0 第 3 条（源码可得）义务。

> 上游原始 README 保留在 [`UPSTREAM-README.md`](UPSTREAM-README.md)。

## 相对上游的主要改动

上游为 `YGOProUnity_V2`（Unity 5.6.7 时代的 YGOPro v2 Unity 客户端）。本分支在其上完成如下开发：

### 1. RD（超速决斗 / Rush Duel）模式

- 模式总闸与卡池双通道，RD 与 OCG 共用同一客户端、可分别进入
- RD 独立卡组目录（`deck_rd/`）、独立回放目录、独立背景图
- RD 人机对战（`rd/ai` 数据包 + `AIRoom` 按模式路由子进程）
- RD 主菜单「资源更新」入口：读取 `rd/update/*.ypk` 并热更新（白名单 + staging + 台账）
- RD 徽标与菜单项按卡池收敛、卡组记忆按模式隔离

### 2. 对局撤回（Undo）

- 人机对局的**真撤回**：同种子重开 + 历史入站消息流喂回，停在目标决策点
- 静默重建（不演出、不推进节拍），按下即本地回退画面
- 只认人工决策点，自动代答不计入撤回点

### 3. 视角

- 新增「俯视角（平面图）」开关：相机由 60° 倾斜抬到 90° 正俯视，牌桌变平面图
- 俯视下场地、手牌与卡上文字/图标按视角自适应；对局途中切换视角立即重摆，无需重开

### 4. 萌卡（MyCard）天梯接入

- 主菜单提供账号登录入口，可按**竞技 / 娱乐**两种天梯匹配对战
- 匹配态「回环」：打完一局天梯、匹配中掉线时回到竞技场界面，不再被丢回服务器列表；
  人机、残局、卡组测试、手动进服等非匹配路径的返回目标不受影响
- 连接层健壮性：连接对象带代际（撤回重开产生的迟到断线事件按代际丢弃）、
  收发各一条常驻线程、连接 / 接收 / 发送三种超时、TCP KeepAlive、
  瞬时 socket 错误退避重试、决斗中空闲心跳

> 该模块为第三方提供（作者 Nanahira），其再分发条件见 [`THIRD-PARTY.md`](THIRD-PARTY.md)。
> 本仓库不含任何账号、密码或密钥，登录凭据由使用者输入并保存于本地。

### 5. 其他功能与修复

- 卡组记牌：悬停查看卡组剩余牌、摊开卡组就地显示真卡面
- 更新机制：在线数据更新统一走 CDN，支持手动触发与强制重下
- 联机房间：服务器密码历史按服务器分桶、上/下键前缀过滤填入
- AI 子进程输出留证与卡死现场快照（排查用）
- UI：标题、图标、设置项文案、窗口布局、字体与缩放

完整逐条记录见提交历史。

## 构建

**Unity 版本：`2021.3.45f1c2`**（见 `ProjectSettings/ProjectVersion.txt`）

1. 用上述版本打开本工程
2. 打开场景 `Assets/main.unity`
3. 构建 Windows x64 Standalone

### 决斗内核

决斗内核以独立进程 `AI.Server.exe` 形式运行，其 C++ 源码工程位于 `AI_core_vs2017solution/`（**不随本仓库分发**）。
默认情况下无需自行编译，使用发布包中附带的 `AI.Server.exe` 即可。

### `devtools/`

| 文件 | 用途 |
| --- | --- |
| `unpack_rd.py` | 从 RD 源卡包（`.ypk`）解出 RD 数据库、卡图与 AI 数据，生成 `rd/` 布局 |
| `pack_rd_update.py` | 打包 `rd/update/*.ypk` 热更新包 |
| `rd_data_layout.md` | RD 数据分发布局说明与源包指纹清单 |
| `verify_ui4.py` | 界面改动的自动化验收脚本 |

## 本仓库**不包含**的内容

本仓库只含**代码与工程配置**，外加上游工程自带的少量启动必需素材
（`sound/` 下的引擎音效、`texture/common/` 的两张默认桌布）。
以下资源不在仓库内，需自行准备（与上游仓库约定一致）：

- 卡片数据库（`cdb/`）
- 卡片效果脚本（`data/`，Lua）
- 卡图与场地（`picture/`、`texture/` 的其余部分）
- 卡包与扩展（`expansions/`、`pack/`）
- 机器人程序与数据（`WindBot/`、`rd/ai/`）

上述资源中，卡图、卡片数据与脚本的版权归 **KONAMI** 及卡牌数据社区所有，本项目**不主张**其任何权利，也不以本仓库形式再分发。
